## 2. 白と金の候補・コントラストの再計算

| 候補 | 色 | 用途 |
| --- | --- | --- |
| 白 | #FFFFFF | 基本背景 |
| 濃い茶 | #1F1B12 | 本文、金の面上の文字、操作に必要な枠 |
| 濃い金 | #8A6A12 | 白上の文字・リンク、操作に必要な枠 |
| 明るい金 | #D4AF37 | 飾り線・印・面。白上の文字や必要な操作枠には使わない |

sRGBの各成分を255で割った値cを、c ≤ 0.04045なら c/12.92、それ以外なら ((c+0.055)/1.055)^2.4 に変換。相対輝度L = 0.2126R + 0.7152G + 0.0722B。比率 = (明るい側のL+0.05)/(暗い側のL+0.05)。手元のJavaScriptで計算し、モックアップ末尾でも同じ式の結果を表示する。輝度は白1、濃い茶0.01118845、濃い金0.15755014、明るい金0.44932828。

| 前景 / 背景 | 比率（小数2桁） | 本文 ≥4.5 | 大きな文字・必要な部品の枠 ≥3 | 採用可能な用途 |
| --- | ---: | --- | --- | --- |
| #1F1B12 / #FFFFFF | 17.16:1 | 可 | 可 | 本文・見出し |
| #8A6A12 / #FFFFFF | 5.06:1 | 可 | 可 | リンク・枠・小見出し |
| #D4AF37 / #FFFFFF | 2.10:1 | 不可 | 不可 | 意味を担わない飾りだけ |
| #1F1B12 / #D4AF37 | 8.16:1 | 可 | 可 | 金の帯・ボタン上の文字と枠 |
| #FFFFFF / #8A6A12 | 5.06:1 | 可 | 可 | 濃い金のボタン上の文字 |
| #8A6A12 / #D4AF37 | 2.41:1 | 不可 | 不可 | この文字・必要な枠の組み合わせは使わない |

合否は丸める前の比率で判定。大きな文字は通常24px以上、太字約18.67px以上を目安とする。明るい金の面に白文字は使わない。白背景に明るい金のボタンを置く場合、濃い茶の枠・文字を付けて操作の境界を明示する。リンクは下線も付け、色だけに依存しない。フォーカスは白上では濃い金、金の面上では濃い茶とし、将来の実装時にhover・focus・disabled等も再計算する。配色表だけでサイト全体のWCAG AA適合を保証するものではない。

## 3. 三つの案

三案ともページのURLと情報を残し、トップ・Product・Companyの見せ方を比較する。ヘッダー/フッターの導線は共通。文章は短い見出し＋読める本文。効果や削減率を根拠なく載せない。NURVISは記録案や情報確認を支えると説明し、「記録の確定と最終の判断は看護師・医師。実施は施設の手順・医師の指示に従う」をProductに残す。申し送りは将来の表示案として扱い、現行で利用できると断定しない。

HTMLとPNGは、各案のトップ・Product・Companyを縦に並べた比較ボード。実際の全コンテンツの再実装ではなく、配置・色・文字量を判断するための抜粋。写真・画面・動画はすべて作り物の枠で、外部読込みはしない。CTA、メニュー、動画枠は静的表示。日本語の画面のみ作成し、英語版の文字の長さは実装前に別途確認する。

### A：静かな白（余白が主役）— おすすめ度：高

Issueの理由：落ち着いた印象とコントラストを保ちやすく、現行の文字アニメも活かせる。金は細い飾り線と小さな印、濃い金は文字と枠。トップは一画面一メッセージを優先し、製品情報は次の段へ。写真は主役にせず、会社の紹介で小さな候補枠だけにする。フォントは現行を出発点とする。

トップ：
```text
[peaceful] Vision Product Research Company News Contact [JA/EN]
--------------------------------------------------------------
        その手の温もり、
        語りかける声。                  ─ 金の飾り線
        [ NURVISを見る：濃い金の枠 ]
--------------------------------------------------------------
[製品を短く紹介]  [Product内デモへのリンク]
[News] → [研究・構想への導線] → [問い合わせ] → [フッター]
```
Product：
```text
[NURVIS：記録と情報確認を、その場で支える]
[記録案]           [情報確認]          [確認して確定]
[人の最終判断・施設手順の注意]
[手動・無音のデモ動画：白い余白＋濃い金の枠]
[動画の一部は画面イメージです]
[利用の流れ] → [導入・FAQ・将来の案] → [問い合わせ]
```
Company：
```text
[現場から、次のケアを考える]
[理念・紹介本文                  ] [小さな写真候補枠]
[代表・チーム紹介] → [会社概要の表]
[参加バッジ] → [問い合わせ] → [方針文書への導線]
```
スマホ：ヘッダー → 一つの見出し → CTA → 本文/カードを一列 → 動画/注記 → 下段情報。Companyは本文 → 写真枠 → 概要。

動画：トップには静止リンクだけ。Productの働きと注意事項の後に主デモ。Companyには埋め込まずProductへ導線。YouTubeを残す場合はProduct下段の補足に置き、主デモと重複するかMJが判断。両方とも自動再生なし、初期無音、音声を勝手に出さず、再生・音声操作は利用者が行う。注記を各プレイヤーの直下に残す。文字アニメを残すなら情報が読める静止状態と動きを減らす設定への対応も必要。粒の背景は比較画像では置かず、残すかMJが決める。

### B：白と金の面（金の帯を使う）— おすすめ度：中

Issueの理由：印象は強いが、金の面上の文字色を厳しく管理する必要がある。見出し帯・問い合わせの面を明るい金にし、必ず濃い茶で書く。本文の白い領域との切り替えで情報を整理する。写真は白いカード内に収める。

トップ：
```text
[peaceful]                         [ナビ・JA/EN]
[======= 金の帯：現場の声から、記録を支える =======]
[濃い茶の本文]                       [デモを見る]
[白：記録案] [白：情報確認] [白：人が確定]
[白：News・研究・構想] → [金：問い合わせ]
```
Product：
```text
[金の帯：NURVIS / 人の判断を支える]
[白：働きの3カード] → [白：安全の注意]
[白：手動・無音のデモ動画 ＋ 画面イメージ注記]
[白：利用の流れ・導入・FAQ] → [金：問い合わせ]
```
Company：
```text
[金の帯：peacefulの考え方]
[白：代表・チーム本文]              [写真候補枠]
[白：会社概要・参加バッジ]
[金：問い合わせ] → [フッター]
```
スマホ：ヘッダー → 金の帯の見出し/本文/CTA → 白いカードを一列 → 動画/注記 → 詳細 → 金の問い合わせ。Companyは紹介 → 写真枠 → 概要。

動画：トップの金の帯のCTAからProductのデモへ。Productは最初の働き・注意の後、白い面にデモを置く。Companyは埋め込まずProductへの導線。補足YouTubeはProduct下段の候補。どちらも自動再生なし・初期無音、操作して再生し、各動画の直下に画面イメージ注記。動画を金の飾り枠だけで囲まず、必要な操作枠は濃い茶にする。

### C：白のページ＋NURVISの画面を大きく見せる — おすすめ度：中

Issueの理由：製品が一目で伝わるが、画面写真・動画の用意とMJによる内容確認が必要。白い面に大きな作り物の画面を置き、金は下線と小さな印に絞る。トップの画面の横には、短い説明と人の最終判断を置く。実在の患者・利用者の顔や名前、本物の記録、特定の病院・施設につながる表示は使わない。

トップ：
```text
[peaceful]                                      [ナビ・JA/EN]
[大きな画面イメージ/手動動画] [NURVISの短い説明・注意・CTA]
[画面イメージ注記]
[記録の作り物の画面] [質問の作り物の画面] [申し送り：将来の表示案]
[News・研究・構想] → [問い合わせ]
```
Product：
```text
[NURVISの説明・人の最終判断]
[大きな手動・無音デモ動画：最初の説明の直後]
[動画の一部は画面イメージです]
[画面枠＋記録案の説明] [画面枠＋情報確認の説明]
[利用の流れ・導入・FAQ・将来の案] → [問い合わせ]
```
Company：
```text
[理念・会社紹介]                    [写真候補枠：実物未掲載]
[代表・チーム紹介] → [会社概要]
[製品へ：大きな画面候補の小版] → [バッジ・問い合わせ]
```
スマホ：ヘッダー → 短い説明/人の判断 → 大きな画面/動画 → 注記 → CTA → 3つの画面枠を一列 → 下段。Companyは理念 → 写真枠 → 概要 → 製品リンク。

動画：トップに静止ポスター付き主デモ、Productでは最初の説明・注意の直後。Companyの画面候補は静止リンクのみ。トップとProductの両方とも自動再生なし・初期無音、利用者の操作で再生し、プレイヤー直下に注記。YouTubeは残す場合でもProduct下段の補足だけ。現在の動画の公開可否をこの提案で再認定せず、使うポスター・動画全体をMJが確認するまで画像は作り物の枠にとどめる。

## 5. 見た目を実装するときの検索・AI向け確認

以下は今回コードを変更して実行する検査ではなく、後続実装の受入チェック。画面の文字と検索用の説明を食い違わせない。

- [ ] JAの全既存URLとNews詳細が表示でき、ENの6種類のページと各News詳細が表示できる。

- [ ] 双方があるページはhreflangのja/en/x-defaultを維持し、言語切り替えは対応する同じページへ向かう。

- [ ] robots.txtのクロール許可とsitemapの指定を維持する。
- [ ] sitemap.xmlのJA/ENページ・News記事・相互alternates・privacy/security-policyを維持する。MJのnoindexとsitemap除外を維持する。

## 6. MJに決めてほしいこと

1. 全体はA（推奨）・B・Cのどれか。ページごとに組み合わせるなら対象を指定してほしい。
2. 金の最終候補：白上の文字/必要な枠は濃い金 #8A6A12、飾り/面は明るい金 #D4AF37でよいか。別の色なら採用前に全組み合わせを再計算する。
3. Homeの粒の背景をなくすか、目立たない形で残すか。文字アニメを残すか。比較画像は静止・粒なし。
4. フォントは現行Geist設定を基準に維持するか、変えるか。変更する場合、日本語/英語の読みやすさ・利用条件を確認する。
5. 英語版も同時に見た目を変えるか。今回のPNGは日本語のみで、既存ENのURLと検索対応は残す。
6. デモのトップ配置はリンクだけ（A/B）か、その場で手動再生（C）か。Productの補足YouTubeは残すか。両方とも自動再生なし・初期無音にする方針でよいか。
7. Cの画面・動画・写真、A/Bの会社写真を用意するか。公開素材は作り物の記録だけで、個人情報・実施設を特定する情報がないことをMJが確認する。
8. 選択後にwebsite-2（配色・共通部品）→website-3（各ページ・動画）を進める。今回の文書PRの合流と、本番の見た目変更は別の承認でよいか。
